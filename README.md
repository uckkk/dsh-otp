# dsh-otp · 一次性密码 TOTP/HOTP

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-otp
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-otp"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-otp
```

> 安装即在本机运行第三方代码，请自行审阅源码。
